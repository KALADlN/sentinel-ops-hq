# Sentinel Ops Operations Flow

## Operational Loop
1. Opportunity detected
2. Opportunity qualified
3. Vendor matching initiated
4. Proposal workflow opened
5. Compliance review completed
6. Pricing review completed
7. Proposal submitted
8. Result tracked
9. Lessons recorded

## Dashboard States
### Green
Operationally stable

### Yellow
Deadline approaching

### Orange
Vendor coordination required

### Red
Critical operational issue

## Proposal Pipeline States
- Intake

- Drafting
- Pricing
- Review
